SEFOP

Software Engineering Framework for Optimization. Most optimization code is a throwaway research script — solved once, never maintained. SEFOP applies real software-engineering discipline — Clean Architecture, dependency injection, full test coverage, CI/CD — to optimization systems, so they can be trusted, extended, and shipped like any other production software.

Problem

An unbounded knapsack problem

Given a budget and a weight limit, pick the combination of products that maximizes total calories.

Mathematical formulation
Sets — I: candidate products, indexed by i ∈ I
Parameters — price·i, weight·i, calories·i for each i ∈ I; B (budget); W (weight limit)
Decision — xᵢ ∈ ℤ≥0 for each i ∈ I (units of product i selected)
Maximize — Σ calories·i · xᵢ
subject to Σ price·i · xᵢ ≤ B (budget)
subject to Σ weight·i · xᵢ ≤ W (weight limit)
xᵢ ∈ ℤ≥0 for all i ∈ I (integrality)
Example — data/2/data.json

Solving pipeline

Four pluggable solver strategies

Enumeration
Brute force — exhaustive search for small problems
MIP (HiGHS)
Exact optimal solution via open-source solver
MIP (SCIP)
Exact optimal via Google MathOpt backend
Heuristic
Fast, approximate — for large-scale problems
CI / CD

Shipped like production software

Four workflows run in parallel on every push and PR, plus a scheduled security scan. On a clean main-branch build, the app auto-deploys.
